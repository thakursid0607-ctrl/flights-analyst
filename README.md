Flight Data Analysis & Interactive Dashboard :-

This project analyzes airport operations, flight numbers, aircraft counts, airline distributions, and schedules using Python, and visualizes the insights through an interactive Streamlit dashboard.


FeaturesData Processing:-

Cleans and merges airport details, flight schedules, aircraft IDs, and airline information.Core Analysis: Calculates the total number of flights per airport, active aircraft counts, airline market shares, and regular departure/arrival timings.Interactive Dashboard: Built with Streamlit to filter and view real-time metrics, busiest routes, and schedule trends.
